# Installation Site Requirements

**Audience:** All internal users
**Revision:** 2024-12

## Dock pit requirements

### Dimensions
| Leveler model | Pit depth (minimum) | Pit width | Pit length |
|---|---|---|---|
| MD-5000 | 12" | platform + 2" | platform + 4" |
| MD-7000 | 12" | platform + 2" | platform + 4" |
| MD-9000 | 16" | platform + 2" | platform + 6" |

### Concrete
- Compressive strength: **3,000 psi minimum** at 28 days
- Reinforcement per Meridian pit drawing (available on request)
- Embed angle iron flush with dock face for mounting

### Drainage
Pit floor must slope **1/4 inch per foot** toward a designated drain point. Pits without drainage will accumulate water and accelerate corrosion — this is a common cause of warranty disputes.

## Electrical service

| Model | Requirement |
|---|---|
| MD-5000 | None |
| MD-7000 | 208/230/460V, 3-phase, 30A dedicated circuit, fused disconnect within 20 ft |
| MD-9000 | None (air-powered; control station uses 120V 15A) |
| RapidRoll 400 | 208/230/460V, 3-phase, 20A dedicated |
| ThermaGuard 600 | 120V 15A for standard 1/2 HP operator |
| DockGuard | 120V 15A plus air supply (see below) |

## Compressed air

For MD-9000 and DockGuard:
- 80–100 psi supply pressure
- 3/4" inside-diameter supply line recommended
- 4 cfm typical average demand per MD-9000
- FRL (filter-regulator-lubricator) assembly recommended, customer-supplied

## Approach and clearances

- **Tractor-trailer approach:** minimum 50 ft straight approach from dock face
- **Turning radius:** minimum 60 ft for 53-ft trailers
- **Overhead clearance:** 14 ft minimum at dock face
- **Canopy projection:** coordinate with door header to prevent interference

## Site preparation checklist (customer scope)

- [ ] Pit constructed to spec with drainage
- [ ] Concrete cured to rated strength
- [ ] Electrical service installed to disconnect location
- [ ] Compressed air supply to dock (if applicable)
- [ ] Dock face prepared (bumpers, seals) per separate drawing
- [ ] Unrestricted access for installation equipment (fork truck, hoist)
